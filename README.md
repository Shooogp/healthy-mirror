# مرآة الغذاء الصحي

برنامج يُفتح على سبورة الصف: يشغّل الكاميرا فيرى الطلاب صفّهم، وبينهم أطعمة ثلاثية الأبعاد واقعية — لدرس الغذاء الصحي، العلوم، الصف الأول.

- **ضيوف في صفّنا:** تلمس المعلمة أي طعام فيكبر، ويُسأل الصف: صحي أم غير صحي؟
- **افتح فمك:** يقف طالب أمام السبورة؛ يفتح فمه للطعام الصحي ويغلقه لغير الصحي.

الصورة تُعالَج داخل المتصفح فقط، ولا تُسجَّل ولا تُرسَل إلى أي مكان.

المجسّمات في `models/` مولّدة في Meshy.

## مغامرة الأبطال في مملكة الغذاء الصحي

البرنامج الكامل للحصة (التعلم القبلي، والمحطات التسع، وكنز الصحة) في مجلد `adventure/`، ويُفتح من:
https://shooogp.github.io/healthy-mirror/adventure/

المحطة السادسة فيه هي هذه المرآة، وتعمل بالكاميرا داخل المغامرة.
